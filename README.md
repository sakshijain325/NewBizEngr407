# Homeward

Pet matchmaking prototype for ENGR 407.

Open `index.html` in a browser (or use VS Code's Live Server extension) to run it. Everything is in one file: styles, sample animal/provider data, the quiz, the matching score, and the shelter dashboard.

Where to edit:
- `ANIMALS` / `PROVIDERS`: sample listings
- `QUESTIONS`: quiz questions and answer options
- `score()`: the matching logic (fit score, reasons, concerns)
- `INQ`: sample shelter inquiries
